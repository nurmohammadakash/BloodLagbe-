# Blood-Lagbe frontend — first implementation

This is the first homepage implementation based on the selected dark-charcoal/red prototype.

## Copy into your existing client

Copy these files/folders into `E:\Blood-Lagbe\client`:
- `index.html`
- `src/css/main.css`
- `src/js/main.js`
- `pages/login.html`
- `pages/register.html`

Keep your existing `public`, `assets`, `context`, `services`, etc. folders.

## Run
From `E:\Blood-Lagbe\client`:
```bash
npm run dev
```
Then open the Vite URL, normally `http://localhost:5173/`.

## Included
- Dark charcoal + red visual system
- Animated hero blood drop / ECG
- Floating particles and scroll-reveal animations
- Animated statistics counters
- Responsive navigation
- Urgent blood request cards
- Interactive OpenStreetMap/Leaflet donor map
- Browser geolocation button
- Nearby donor panel
- 3 social-awareness YouTube embeds
- Responsive mobile layout
- Login/register placeholder routes for the next API-integration step

The donor coordinates are demo data for the visual prototype; later we will replace them with Blood-Lagbe database/API data.
